# Syncfusion&reg; ASP.NET MVC DOCX Editor

The Syncfusion<sup style="font-size:70%">&reg;</sup> [ASP.NET MVC DOCX Editor](https://www.syncfusion.com/docx-editor-sdk/asp-net-mvc-docx-editor?utm_source=github&utm_medium=github&utm_campaign=github-asp-net-mvc-docx-editor-examples) (Document Editor) is a feature-rich, user-interactive component that enables creating, editing, viewing, and printing Word documents with advanced formatting, editing capabilities, and broad support for document import and export formats.

# Key Features

* [Opens](https://help.syncfusion.com/document-processing/word/word-processor/asp-net-mvc/import?utm_source=github&utm_medium=listing&utm_campaign=github-asp-net-mvc-docx-editor-examples) the native `Syncfusion Document Text (*.sfdt)` format documents in the client-side.
* [Saves the documents](https://help.syncfusion.com/document-processing/word/word-processor/asp-net-mvc/export?utm_source=github&utm_medium=listing&utm_campaign=github-asp-net-mvc-docx-editor-examples) in the client-side as `Syncfusion Document Text (*.sfdt)` and `Word document (*.docx)`.
* Supports document elements like text, [image](https://help.syncfusion.com/document-processing/word/word-processor/asp-net-mvc/image?utm_source=github&utm_medium=listing&utm_campaign=github-asp-net-mvc-docx-editor-examples), [table](https://help.syncfusion.com/document-processing/word/word-processor/asp-net-mvc/table?utm_source=github&utm_medium=listing&utm_campaign=github-asp-net-mvc-docx-editor-examples), fields, [bookmark](https://help.syncfusion.com/document-processing/word/word-processor/asp-net-mvc/bookmark?utm_source=github&utm_medium=listing&utm_campaign=github-asp-net-mvc-docx-editor-examples), [shapes](https://help.syncfusion.com/document-processing/word/word-processor/asp-net-mvc/shapes?utm_source=github&utm_medium=listing&utm_campaign=github-asp-net-mvc-docx-editor-examples), [section](https://help.syncfusion.com/document-processing/word/word-processor/asp-net-mvc/section-format?utm_source=github&utm_medium=listing&utm_campaign=github-asp-net-mvc-docx-editor-examples), [header and footer](https://help.syncfusion.com/document-processing/word/word-processor/asp-net-mvc/header-footer?utm_source=github&utm_medium=listing&utm_campaign=github-asp-net-mvc-docx-editor-examples).
* Supports the commonly used fields like [hyperlink](https://help.syncfusion.com/document-processing/word/word-processor/asp-net-mvc/link?utm_source=github&utm_medium=listing&utm_campaign=github-asp-net-mvc-docx-editor-examples), page number, page count, and table of contents.
* Supports formats like [text](https://help.syncfusion.com/document-processing/word/word-processor/asp-net-mvc/text-format?utm_source=github&utm_medium=listing&utm_campaign=github-asp-net-mvc-docx-editor-examples), [paragraph](https://help.syncfusion.com/document-processing/word/word-processor/asp-net-mvc/paragraph-format?utm_source=github&utm_medium=listing&utm_campaign=github-asp-net-mvc-docx-editor-examples), [bullets and numbering](https://help.syncfusion.com/document-processing/word/word-processor/asp-net-mvc/list-format?utm_source=github&utm_medium=listing&utm_campaign=github-asp-net-mvc-docx-editor-examples), [table](https://help.syncfusion.com/document-processing/word/word-processor/asp-net-mvc/table-format?utm_source=github&utm_medium=listing&utm_campaign=github-asp-net-mvc-docx-editor-examples) and [page settings](https://help.syncfusion.com/document-processing/word/word-processor/asp-net-mvc/section-format?utm_source=github&utm_medium=listing&utm_campaign=github-asp-net-mvc-docx-editor-examples).
* Provides support to create, edit, and apply [paragraph and character styles](https://help.syncfusion.com/document-processing/word/word-processor/asp-net-mvc/styles?utm_source=github&utm_medium=listing&utm_campaign=github-asp-net-mvc-docx-editor-examples).
* Provides support to [find and replace](https://help.syncfusion.com/document-processing/word/word-processor/asp-net-mvc/find-and-replace?utm_source=github&utm_medium=listing&utm_campaign=github-asp-net-mvc-docx-editor-examples) text within the document.
* Supports all the common editing and formatting operations along with [undo and redo](https://help.syncfusion.com/document-processing/word/word-processor/asp-net-mvc/history?utm_source=github&utm_medium=listing&utm_campaign=github-asp-net-mvc-docx-editor-examples).
* Provides support to [cut](https://help.syncfusion.com/document-processing/word/word-processor/asp-net-mvc/clipboard#cut?utm_source=github&utm_medium=listing&utm_campaign=github-asp-net-mvc-docx-editor-examples), [copy](https://help.syncfusion.com/document-processing/word/word-processor/asp-net-mvc/clipboard#copy?utm_source=github&utm_medium=listing&utm_campaign=github-asp-net-mvc-docx-editor-examples), and [paste](https://help.syncfusion.com/document-processing/word/word-processor/asp-net-mvc/clipboard#paste?utm_source=github&utm_medium=listing&utm_campaign=github-asp-net-mvc-docx-editor-examples) rich text contents within the component. Also allows pasting simple text to and from other applications.
* Provides support to insert, and edit [form fields](https://help.syncfusion.com/document-processing/word/word-processor/asp-net-mvc/form-fields?utm_source=github&utm_medium=listing&utm_campaign=github-asp-net-mvc-docx-editor-examples).
* Provides support to insert, and edit [comments](https://help.syncfusion.com/document-processing/word/word-processor/asp-net-mvc/comments?utm_source=github&utm_medium=listing&utm_campaign=github-asp-net-mvc-docx-editor-examples).
* Provides support to track the inserted and deleted content.
* Provides support to perform [spell checking](https://help.syncfusion.com/document-processing/word/word-processor/asp-net-mvc/spell-check?utm_source=github&utm_medium=listing&utm_campaign=github-asp-net-mvc-docx-editor-examples) for any input text.
* Allows user interactions like [zoom](https://help.syncfusion.com/document-processing/word/word-processor/asp-net-mvc/scrolling-zooming#zooming?utm_source=github&utm_medium=listing&utm_campaign=github-asp-net-mvc-docx-editor-examples), [scroll](https://help.syncfusion.com/document-processing/word/word-processor/asp-net-mvc/scrolling-zooming?utm_source=github&utm_medium=listing&utm_campaign=github-asp-net-mvc-docx-editor-examples), select contents through touch, mouse, and keyboard.
* Provides intuitive UI options like context menu, [dialogs](https://help.syncfusion.com/document-processing/word/word-processor/asp-net-mvc/dialog?utm_source=github&utm_medium=listing&utm_campaign=github-asp-net-mvc-docx-editor-examples), and [navigation pane](https://help.syncfusion.com/document-processing/word/word-processor/asp-net-mvc/find-and-replace#options-pane?utm_source=github&utm_medium=listing&utm_campaign=github-asp-net-mvc-docx-editor-examples).
* Provides a [ribbon interface](https://help.syncfusion.com/document-processing/word/word-processor/asp-net-mvc/ribbon?utm_source=github&utm_medium=listing&utm_campaign=github-asp-net-mvc-docx-editor-examples) similar to Microsoft Word, with tab-based commands for quick and intuitive access to features.
* [Localizes](https://help.syncfusion.com/document-processing/word/word-processor/asp-net-mvc/global-local?utm_source=github&utm_medium=listing&utm_campaign=github-asp-net-mvc-docx-editor-examples) all the static text to any desired language.
* Allows to create a lightweight Word viewer using module injection to view and [prints](https://help.syncfusion.com/document-processing/word/word-processor/asp-net-mvc/print?utm_source=github&utm_medium=listing&utm_campaign=github-asp-net-mvc-docx-editor-examples) Word documents.
